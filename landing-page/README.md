# Nexus-AI Landing Page

Next.js-based landing page for Nexus-AI.

## Setup

```bash
cd landing-page
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output will be in the `out` directory.

## Pages

- `/` - Home page
- `/docs` - Documentation
- `/components` - Component list
- `/license` - License information
