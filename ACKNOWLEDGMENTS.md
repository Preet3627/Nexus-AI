## Inspiration

### Thuki
**Nexus-AI** was inspired by and borrows concepts from **Thuki**, created by Logan Nguyen (@quiet_node).

**Thuki** is a floating AI secretary for macOS that provides:
- Spotlight-style overlay UI
- Double-tap Control key activation
- Slash command suggestions
- Context-aware quote pre-filling
- Image attachment support

Thuki is licensed under the **Apache License 2.0**. Source code derived from Thuki has been substantially modified for Nexus-AI.

**Thuki Repository:** https://github.com/quiet-node/thuki
