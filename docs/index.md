# Nexus-AI Documentation

Welcome to the official documentation for **Nexus-AI** - a native macOS AI assistant with Thuki-inspired floating overlay, multi-LLM support, and enterprise-grade security.

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/Nexus-AI.git
cd Nexus-AI

# Install dependencies
npm install

# Build the project
npm run tauri build
```

### Usage

1. **Activate**: Double-tap `Control` key (⌃⌃)
2. **Chat**: Type your message and press Enter
3. **Commands**: Use `/screen`, `/think`, `/summarize`
